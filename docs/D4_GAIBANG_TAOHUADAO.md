## 4. 世界事件入口

原 `p_person.lua::地图系统_人物` 继续统一负责门派 NPC 事件。

新增回归：

```text
trig_event("初入丐帮-洪七公")
  → p_person wait_case
  → G.call("初入丐帮-洪七公")

trig_event("初入桃花岛-黄药师")
  → p_person wait_case
  → G.call("初入桃花岛-黄药师")
```

两次事件结束后都必须重新进入 `wait_case`。
