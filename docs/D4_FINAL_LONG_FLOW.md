## 9. 长流程调试中发现的问题

### 9.1 缺少 co module

首次接入 CI 时长流程 fixture 没有提供原 `p_order.lua` 需要的 `co`。

修正：

- 使用与其他原程序 smoke 相同的 coroutine shim；
- 不改产品 runtime。

### 9.2 经脉默认状态

完整开局第一次真正执行原 `指令_存储属性` 时，测试 fixture 中部分经脉 placeholder 没带：

`打通数量 = 0`

固定上游 `o_jm.lua` 的九条经脉本来全部定义：

- `打通数量 = 0`
- `是否打通 = false`

长流程 fixture 因此显式补齐这组固定上游默认状态，继续执行原属性计算，没有 stub 掉 `指令_存储属性`。

### 9.3 武当好感初始化

最初使用 `add_love(161, 50)` 作为 fixture。

原 `add_love` 自带 100 上限，所以改为：

`set_love(161, 50)`

之后真实切磋胜利得到 53。

### 9.4 城市地图 program 装载

长流程最初只加载剧情子集，导致：

`地图_进入地图`

被报告为 missing call。

进一步检查正式 Web loader 后确认：

`p_citymap_system.lua`

本来就是 `CORE_PROGRAMS`，正式浏览器环境会加载。

因此最终修复是让长流程 fixture 同样加载 core citymap program，而不是在 `gf_web.lua` 新增剧情专用 fallback。
