# 资源扫描基线说明

当前资源扫描基于固定上游 revision：

```text
c7b6180b9d79aa5df33f7e8375d6dd88d67a8cc8
```

CI 会先获取该 revision 的完整 Git tree 索引，再扫描当前已经纳入 Web Runtime 的 Lua / 数据源中的资源 ID。

当前已验证基线：

```text
JY3 上游文件：11673
扫描 Lua 文件：30
唯一资源引用：343
已缓存：2
上游存在但未缓存：335
动态 ID 表达式：6
真实缺失：0
```

其中 `uncached` 不代表原项目缺素材，只代表当前离线发行包还没有把该资源复制进来。随着地图、UI、动画、音频、剧情模块继续接入，该集合会逐步转成 `cached`。

动态 ID（例如 `0x560b1000 + code`）只记录基址，不按基址对应的单个固定文件做缺失判断。

Spine / particle 等结构化资源不使用简单的固定后缀推导；资源定位层只负责标记资源族，具体 bundle 内容解析留给动画系统。
