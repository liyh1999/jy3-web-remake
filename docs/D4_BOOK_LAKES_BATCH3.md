## 4. 连续剧情测试桥修正

连续执行《连城诀》时首次覆盖到原 `talk0` 的浏览器暂停/恢复路径。

浏览器产品端 `src/app.js` 原本已经实现 `JYWeb.showTalk()`。问题来自新 smoke 的测试 Web 桥最初没有模拟 `showTalk(..., resume)` 的异步暂停/回调语义。

最终测试桥改为：

```text
__jy_run
→ 原剧情遇到 talk0
→ web.showTalk 保存 resume callback
→ Lua coroutine yield
→ 测试驱动 callback
→ 原 coroutine 继续
→ 如遇下一个 talk0 再重复
→ 剧情自然结束
```

因此没有给具体天书增加 Web 特判，也没有修改产品剧情状态机。
