## 4. 世界事件入口

原 `p_person.lua::地图系统_人物` 仍然统一负责门派 NPC 事件。

自动回归新增：

```text
trig_event("初入少林-慧伦")
  → p_person wait_case
  → G.call("初入少林-慧伦")

trig_event("初入峨嵋派-周芷若")
  → p_person wait_case
  → G.call("初入峨嵋派-周芷若")
```

每个事件结束后 dispatcher 必须再次进入 `wait_case`，确保长期监听不被单次门派剧情破坏。

## 5. Runtime 边界

D4-4C 没有新增少林或峨嵋专用 JS 状态机。

继续复用：

- core `p_order.lua`；
- D4-3 background story scheduler；
- 原 dialogue runtime；
- original battle bridge；
- 原队伍 / 好感 / 物品 / 武学状态；
- Web 平台对地图和 UI 调用的既有兼容层。

门派业务规则仍由固定 upstream Lua 决定。

## 6. Offline

CI 构建 `dist` 后，会重新从：

- `dist/lua`
- `dist/vendor/upstream/JY3/script/04_program`

执行少林与峨嵋 smoke。

因此 D4-4C 要求源码路径和离线分发路径都能直接运行同一份原门派脚本。
